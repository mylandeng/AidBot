# 知识库工作台设计

## 产品约束

- 一个知识库只对应一条产品线，`product_line` 是创建知识库时必填且唯一的业务字段。
- 旧知识库可以原地补充产品线，不迁移文档、不重建索引。
- 同一知识库可以包含该产品线下主控、遥控器、充电底座、电池、使用手册和售后案例等不同组件知识。
- 管理员聊天选择知识库后，系统从知识库派生会话产品线，并只在该知识库内检索。
- 同一会话固定知识库范围；需要切换时创建新会话。

## 页面结构

### 知识库总览

- 页面右上角提供“添加知识库”。
- 知识库以响应式横向卡片网格展示。
- 每张卡片展示名称、说明、源文档数量、知识片段数量和更新时间，不重复显示产品线标签或装饰性缩写。
- 点击卡片进入知识库详情，不在总览页堆叠导入表单。

### 知识库详情

- 顶部展示返回入口、知识库名称、产品线、源文档总数和片段总数。
- 返回箭头与知识库标题同行；右上角并列提供“编辑”和“添加知识”。
- 编辑弹窗统一维护知识库名称和产品线，旧知识库也从此入口补齐产品线。
- 主体展示源文档列表，每项包含格式、状态、更新时间和片段数量，并保留重新索引、删除操作。

### 添加知识弹窗

- “单条内容”用于录入售后经验、故障处理方案和 FAQ。
- “导入文档”用于导入 Markdown、文本、HTML 和当前后端支持的文档格式。
- 所有内容自动进入当前知识库，不再次要求选择产品线或知识库。

## 交互约束

- 创建、编辑、导入、重新索引和删除的结果优先由页面当前状态表达，不显示额外绿色成功条。
- 错误信息必须保留；知识库、单条知识、会话、访问码等永久删除和批量清空操作必须二次确认。
- 索引状态位于片段数左侧；正常显示“已建立索引”，重建期间显示“正在索引”。
- 重新索引使用圆箭头图标，点击后仅当前条目的图标旋转，后端请求结束后停止。

## 参考结论

阿里云百炼当前知识库管理采用“知识库列表 -> 查看详情 -> 文档与切片管理”的层级；文档列表突出状态和导入信息，文档详情继续下钻到切片。AidBot 保留该管理逻辑，但减少规格、索引参数和数据连接器等当前 MVP 不需要的配置。
