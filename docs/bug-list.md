# AidBot Bug 清单

## 2026-07-22

### 聊天输入/输出区域缺少复制能力
- 用户输入窗口缺少复制按钮。
- 助手输出窗口缺少复制按钮。
- 期望：每条用户输入和每条助手回答都可以单独复制，而不是只提供统一的一键复制。

### 助手输出未按 Markdown 渲染
- 当前回答内容只是按原始文本输出。
- Markdown 标题、列表、代码块、表格、引用等格式没有被渲染。
- 期望：助手回答在聊天窗口中按 Markdown 格式展示。

### 最近会话区域视觉主题不一致
- 最近会话区域目前是浅色样式。
- 期望：最近会话区域与 AidBot 外部界面整体主题保持一致。

### 最近会话展示数量和展开交互需要调整
- 当前最近会话展示过多或没有折叠策略。
- 期望：默认只展示最近 5 条会话。
- 期望：用户点击展开按钮后，再展示剩余会话条目。
- 期望：展开后可以在右侧预留一条较细的滚动条，与外部界面的大滚动条平行。
- 期望：滚动条在用户鼠标未悬停时以浅色弱化或隐藏，鼠标移入最近会话区域时再清晰显示。

### 引用调试区域用途不清
- 当前界面中的“引用调试”区域用途不明确。
- 需要确认该区域是否面向开发调试、管理员排查，还是普通用户可见功能。
- 期望：如果不是普通用户必要功能，应隐藏、移除或移动到更合适的调试/管理员入口。

### 引用片段打分和命中可信度偏假
- 当前引用片段的打分看起来不够可信。
- 有些用户问题本不应该命中知识库，但系统仍然返回了引用片段。
- 这会让用户误以为回答确实有知识库依据，影响来源追溯的可信度。
- 期望：当问题与知识库内容相关性不足时，不应强行展示引用。
- 期望：引用片段需要有更可靠的相关性阈值、无命中状态或低置信度提示。

### 引用命中分数超过 1 且跨组件误命中
- 管理员查看引用来源时出现 `1.0340` 这类超过 1 的命中分数，分数语义不可信。
- 用户问题明确询问“主控”时，系统不应优先命中“充电底座”等不同组件的知识片段。
- 期望：引用命中分数展示范围应限制在 0 到 1。
- 期望：当问题包含明确组件实体时，候选片段如果属于另一个明确组件，且没有相同产品/故障码/版本等强实体重合，应过滤掉。

### 最近会话缺少删除入口
- 最近会话列表只有打开会话能力，没有删除按钮。
- 用户和管理员无法从界面清理不需要的会话记录。
- 期望：每条最近会话都提供删除入口。
- 期望：删除当前打开的会话后，聊天窗口回到新会话状态。
